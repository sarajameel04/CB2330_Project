# Data

The values in `contact_summary.csv` come from the age-group rows of Table 1 in Mossong et al. (2008):

https://doi.org/10.1371/journal.pmed.0050074

Each row is one age group. `n` is the number of participants, `mean_daily_contacts` is the average number of contacts per person per day, and `sd_daily_contacts` is the standard deviation. These are published summary values, not individual participants' records.
